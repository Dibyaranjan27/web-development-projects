## 📜 The Story Behind This Project

This project started as a raw, generic HTML template ("Sided" by TemplateMo). I decided to completely repurpose it into a stunning travel photography portfolio. I overhauled the text, updated the context from a standard corporate theme to a vibrant photography adventure, and adapted the layouts to highlight stunning galleries and travel stories. 

It was a great exercise in taking an existing template and breathing new life into it to fit a specific, creative niche.

*The photos are placeholder high-quality images to show what the final design could look like.*

If you think it turned out cool, feel free to drop a **star ⭐** or **fork it 🍴**!

## 📌 Key Features

- 📸 **Photography Portfolio:** A clean, image-focused layout perfect for showcasing travel galleries and visual stories.
- ✨ **Gallery Rollovers:** Beautiful hover effects and smooth transitions on the image grid.
- 📱 **Responsive Design:** Adapts cleanly to various screen sizes using Bootstrap 4, ensuring the portfolio looks great on mobile phones and desktops.
- 🎨 **Modern UI/UX:** A sleek design with custom typography (Open Sans) and a minimalist, content-first approach.
- ✉️ **Contact Form Integration:** A pre-designed contact section ready to be hooked up to a backend for client inquiries and print orders.

## 🚀 Installation and Usage

Since this is a static web application without any build tools or complex backend requirements, getting it running is extremely simple.

### **1. Clone the Repository**
```sh
git clone https://github.com/Dibyaranjan27/wanderlust-photography.git
cd wanderlust-photography
```

### **2. Open Locally**
Simply open the `index.html` file in your preferred web browser. 
No local server or installation is strictly necessary, though you can use tools like VS Code's "Live Server" extension for hot-reloading if you plan to make edits.
